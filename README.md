# Magic
assembly like programming language for 32 bit systems like pentium mmx

Language simpler than writing prompt to ai!

Documentation in magic.md!
Documentation for vibe coders in vibecodemmx.txt!


Compile with `python magicc.py yourprogram.mmx`

boot.s and build.sh are for making img you can write to floppy disk.
`./build.sh yourprogram.mmx`
